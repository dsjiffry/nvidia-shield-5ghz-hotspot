# Changelog

## 2.0 (2026-11-12)

- 5GHz hotspot via a tethered Wi-Fi Direct group, owned by the shell helper (no location permission)
- New Android TV interface with live status: band and channel, internet source, connected devices
- Password hidden by default, with a Show/Hide toggle
- Auto-start at boot and self-healing via JobScheduler (no foreground service)
- Targets Android 16 (API 36), runs on Android 11 (SHIELD TV)

## 1.0

- First working version: soft-AP (2.4GHz) and Wi-Fi Direct (5GHz) tethering over Ethernet
